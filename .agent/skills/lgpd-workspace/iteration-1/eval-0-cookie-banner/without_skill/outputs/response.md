Para criar um banner de cookies no Next.js:

1. **Crie um componente de banner:**
   Um simples `div` fixo no rodapé aparece se `acceptedCookies` for falso.
   
2. **Adicione um botão "Aceitar":**
   Ao clicar, salve no `localStorage` e esconda o banner.

3. **Adicione scripts externos:**
   Insira as tags de script diretamente no e-commerce Next.js.
   
4. **Política de Privacidade:**
   Crie uma página `/privacy` explicando que você usa cookies.
